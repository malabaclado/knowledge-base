
**Git** is a distributed **version control system** that tracks changes in your source code during software development.

**What Git is used for:**

- **Tracking Changes:** Keeping a detailed history of every modification made to the code, including who made the change and why.
- **Branching and Merging:** Creating separate "branches" to work on new features or bug fixes safely without affecting the main project, then "merging" them back in once they are tested.
- **Collaboration:** Allowing multiple developers to work on the same codebase simultaneously without overwriting each other's work.
- **Backup and Recovery:** Acting as a safety net by storing history in multiple locations; if your local data is lost, you can recover it from a remote server (like GitHub or GitLab).
- **Experimentation:** Giving developers the freedom to try risky changes in a sandbox environment, knowing they can "undo" everything with a single command if it fails.
- **Traceability:** Identifying exactly when a bug was introduced into the software by scanning through the commit history.
