# EM algorithm for AG
Here we'll discuss the Expectation-Maximization algorithm for Asymmetric Gaussian. 

The optimal values for each local AG, $\{\mu_{i}, \sigma_{i}^{2}, r_{i}\}$ and the mixing coefficients $\{\pi_{k}\}$ cannot be easily obtained in closed form. Here we'll describe the EM algorithm which provides a numerical method for estimating these maximum likelihood parameters.
