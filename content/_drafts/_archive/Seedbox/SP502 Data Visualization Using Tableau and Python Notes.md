# 1. Basic Tableau Charts
In this module, we learned how to install **Tableau**, connect to a **dataset**, and create our first **visual**, a bar graph. 

There are two Tableau formats: twb and twbx.

- **TWB** is the default format, and it keeps the data source separate.
- **TWBX** embeds the dataset and makes it easier to share with others. 

We also discussed the key differences between **Dimensions** and **Measures**.
# 2. Exploring Data with Dimensions

In this module, you learned how to **investigate data** using visual formatting like **color** and **sizes**. You also used dimensions like time, categories, and profit as a way to see the dataset from different perspectives. We then applied colors, shapes, and sizes to make interesting features stand out and to investigate these further using filters.
