### 4. Don't overcomplicate

> *If it's hard to read, it's hard to do.*

Tips
1. Make it legible. Use consisten, easy-to-read font.
2. Keep it clean
3. Use straightforward language. Do not use jargons. Explain if not avoidable.
4. Remove unnecessary complexity.
