# Object Oriented Programming
Object-Oriented Programming involves the use of classes, attributes and methods. 

**The Analogy**
Think of a class as a template - which is used in creating objects, which are sometimes called instances. These objects have defined internal variables and functions. These variables are called attributes and the functions are called methods. 

**Example**
The string `str` is a class. When you write `y="Hello"`, python understands it as  `y=str("Hello")` and creates an instance of the string class that holds the data `"Hello"`. This object has attribute such as `len` and methods such as `upper()`. The methods can be called using the operator `.` such as: `y.upper()`

For more information about OOP, check out the [[Object Oriented Programming#^1839f1|references]].
