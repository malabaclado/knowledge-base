# Data Value Chain
The Data Value Chain in order: {Data}, {Information}, {Insights}, {Imperatives}
^1684897595844

This stage of the data value chain refers to the creation and generation of data from its source :: 'Data' stage

This is the stage of the data value chain is where the data is consolidated to a single repository :: 'Information' stage
^1684897991759

This stage in the data value chain is where the data is analyzed for patterns and trends to answer questions like: why it happened and what could likely happen next :: 'Insights' stage

# Analytics Defined

{**Analytics**} progresses data along its value chain, with the purpose of delivering the right decision support to the right people and digital processes at the right time, for the greater good.
^1684898138838

What does analytics as a decision support means?::Analytics as a decision support means that **while analytics can provide the end used (the stakeholders) with data, information, insights and prescribed actions, we should maintain that the end user can still choose to act upon them or not**. The final decision is still with the end user.
^1684898138842

This data analytics role is to develop and maintain an organization's data usage and data security policies. THey are the 'data gatekeepers' of the organization. :: Data Steward
^1684898360481

This data position's role is to design, construct, test and maintain data infrastructures. They ensure data is in sync with various data sources. :: Data Engineers
^1684898360486

This data position's role leverages statistical techniques and creates analytical models to derive new insights from data :: Data Scientist
^1684898360489

This data position's role uses data and derived insights to help organizations make better decisions on a specific functional domain :: Functional Analyst
^1684898360491

This data position's role is to develop and guide data projects. Their expertise is in project management. :: Analytics Manager
^1684898360494
