In linear algebra, an $n$-by-$n$ square matrix $A$ is called invertible (also nonsingular, nondegenerate or regular), if there exists an $n$-by-$n$ square matrix $B$ such that $$AB=BA=I_{n}$$ where $I_{n }$ denotes the  $n$-by-$n$ identity matrix  and the multiplication used is ordinary matrix multiplication. 

 If this is the case, then the matrix $B$ is uniquely determined by $A$, and is called the (multiplicative) inverse of $A$, denoted by $A^{-1}$. Matrix inversion is the process of finding the matrix $A$ that satisfies the prior equation for a given invertible matrix $A$.
