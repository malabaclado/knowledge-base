Workspaces
- `Ctrl+3`: Load workspaces 
- `Ctrl+Shift+3`: Save current workspace
- `Ctrl+Alt+3`: Manage workspaces

Wordy
- `Ctrl+0`: Toggle synonym for currently selected word

Various Complements
- `Ctrl+<space>`: Show suggestions

Closing
- `Ctrl+W`: Close current file
- `Ctrl+Shift+W`: Close all other tabs
- `Ctrl+Alt+W`: Close window


Files
- `Alt+F`: Reveal file in navigation
