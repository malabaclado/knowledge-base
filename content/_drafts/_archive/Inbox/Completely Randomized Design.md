In a **completely randomized design**, experimental units are randomly assigned to all levels of the factor. Any experimental unit has an equal chance/probability of getting selected for any level of the factor. Therefore, the detail name for the completely randomized design can be **completely randomized equal replication design**, or **completely randomized equal replication experiment** due to the equal probability for any experimental unit to be selected for any levels of the factor ([Hinkelmann and Kempthorne 2008](https://www.google.com/url?q=https%3A%2F%2Fwww.theopeneducator.com%2Fdoe%23h.p_ID_261&sa=D&sntz=1&usg=AOvVaw2ix9nFIx4aZRUqDvJ_1Hyt)).

Example:
- Response Variable: Fuel Mileage
- Factor/Treatment: Fuel Type (Type 1, Type 2, Type 3)
- Experimental unit: Vehicle
   
CRB: Each experimeental unit (vehicle) has equal chance to try the factor level (fuel type)

This problem could be solved using a [[One-way ANOVA]].
