PySpark is a Python API for Spark. It is released by the Apache Spark community to support python with Spark.

Key features:
- Real-time computations with low latency
- Compatible with various languages such as Scala, Java, Python and R.
- Provides powerul caching and disk persistence.
- Faster than traditional frameworks (such as mapreduce) for big data processing.
- Work well with RDDs.
