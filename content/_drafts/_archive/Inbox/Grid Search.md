- It is an exhaustive searching through a manually specified subset of the hyperparameter space of a learning algorithm. 
	- A grid search algorithm must be guided by some performance metric, typically measured by cross-validation on the training set or evaluation on a hold-out validation set.
	- Grid Search suffers from the [[curse of dimensionality]].
