# Markov Chain

**What is a Markov Chain ?**
- It is a stochastic model describing a sequence of possible events in which the probability of each event depends only on the state attained in the previous event.
- One property that makes the study of a [[Random process]] much easier is the “[[Markov property|Markov property]]”
-  A **Markov chain** is a Markov process with discrete time and discrete state space.
- It is also known as *homogenous discrete time Markov chains*


---
We can denote a Markov chain by: $$X = (X_{n})_{n\in\mathbb{N}} = (X_{0}, X_{1},X_{2},...) $$

where at each instant of time, the process takes its values in a discrete set $E$ such that $X_{n} \in E, \forall n \in \mathbb{N}$.
