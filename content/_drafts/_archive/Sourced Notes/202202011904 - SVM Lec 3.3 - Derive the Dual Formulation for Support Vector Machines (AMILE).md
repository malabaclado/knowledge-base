# Summary

Recall from [[202202011844 - SVM Lec 3.2 Training of Support Vector Machines (AMILE)]]:

To find the maximum margin hyperplane, we solve the **optimization problem**: $$\min \frac{1}{2}||\text{w}||$$
subject to the constraint: $$y_{i}(\text{w}^{T}\text{x}_{i}+ b) \geq 1$$
wherein (the data encoding) $y_{i}= +1$ for class B and $y_{i} = -1$ for class A.

---

Now, we'll find the dual representation of this problem. The dual formulation shifts the complexity of the constraints into the objective function to eliminate the parameter vector $\text{w}$. 

The *Dual Formulation of the Optimization Problem* is given by
$$\tilde{L} = \sum^{N}_{i=1}\lambda_{i} - \frac{1}{2}\sum^{N}_{i=1}\sum^{N}_{j=1}\lambda_i\lambda_{j}y_iy_j\text{x}^{T}_{i}\text{x}_{j}$$

with constraint:
$$\lambda_{i}\geq 0$$
