Using markdown link: `[filename](file:///<absolute-path>)`

Example case:
```
[statswords.csv](file:///C:/Users/bruno/Dropbox/Obsidian/Vaults/ClippingContents/statswords.csv)
```

Note that any `whitespace` in the path should be replaced by `%20`
