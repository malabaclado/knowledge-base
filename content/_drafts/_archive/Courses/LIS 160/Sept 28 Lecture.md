Types of Computers
1. Embedded Systems - embedded in different hardware like appliances (eg. smart appliances)
2. Mobile Devices - small device you can carry that is capable of computing (eg. smartphones, wearable tech). Important feature is network capability.
3. Personal Computers - Computers intended to be used by a single person (eg. desktop, laptop)
4. Server - listens for requests and responds to clients, expected to be up 24/7.
5. Mainframe computers - computers intended to support millions of transactions. (eg. banks receive a lot of transactions from their clients.)
6. Supercomputers - bigger computing power than mainframe computer. Typically used for research and complex computations.
