# Thesis - Abstract
Title: Short term stock price prediction using support vector regression on Philippine stock markets

Stock price prediction is a challenging task due to the nonlinearity and nonstationary features of financial time series data. The rise of efficient learning machines leads to the development of expert systems that aid in making decisions. Support Vector Regression (SVR) is a supervised machine learning algorithm known for its robustness, sparsity and global optimum solutions. This paper attempts to create a model for predicting the daily close prices of the Philippine Stock Exchange index using SVR. The daily *Open* prices along with three technical analysis indicators were used as predictors: Simple Moving Average (SMA), Weighted Moving Average (WMA) and Relative Strength index (RSI). Each of these indicators have a 10-day, 20-day and 60-day window period variants. Three-year data from June 2015 to June 2018 were used to train the SVR model. Grid Search Cross Validation technique is used to select the best parameters of the model. Three additional Philippine stocks datasets are used to create an SVR model and evaluate its performance. Among the three kernels utilized in the study, the linear kernel produced the best results. Finally, a 10-day forecasting system is proposed based on the obtained SVR model. The predicted values show a mean absolute percentage error of 1.0673% and a root mean squared error of 97.6175. Support vector regression is found to be effective in modeling and short-term prediction of stock prices. This is the first paper to investigate support vector regression on Philippine stock markets.
