# Extending the latent Variable Model of Gaussian to Asymmetric Gaussian
The Asymmetric Gaussian  model is an extension of the concept of latent variable model of single Gaussian model. It can be extended to mixture models and can be applied to pattern recognition and machine learning clustering and classification tasks. 

See: [[Latent Variable Model of the Gaussian]] 

We now introduce the Asymmetric Gaussian model by extending the latent variable model of the Gaussian.
