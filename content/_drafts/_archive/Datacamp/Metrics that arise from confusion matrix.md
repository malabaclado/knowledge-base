In [[Machine Learning|machine learning]], [[accuracy]] is not always a useful metric. For example, you can make a very accurate machine that is bad at predicting, like when you have [[Class Imbalance|class imbalance]].


The Confusion Matrix summarizes the predictive performance of our machine.
![[Pasted image 20220207185036.png]]



From this metric, note that the [[accuracy]] is defined as $$\text{accuracy} = \frac{tp + tn}{tp+tn+fp+fn}$$
or the number of correctly labeled divided by the total number of data sets.

### OTHER METRIC THAT ARISES FROM THE CONFUSION MATRIX
- [[Precision]]
- [[Recall]]
- [[F1 Score]]
