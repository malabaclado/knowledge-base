Types of Error
- Type I: Rejecting $H_0$ when $H_0$ is true.
- Type II: Accepting $H_0$ when $H_0$ is false.

Definition. Power Function
-> the probability that $H_0$ is rejected

Definition. Significance Level
Let C be a critical region of $H_0$.
The size of the critical region $\alpha$ is: $$\alpha = \sup [\Pi_C(\theta)] $$
We call $\alpha$ the significance level of the test.
