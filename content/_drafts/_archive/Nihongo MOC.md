Adding hint fields:

Add this in front template:

```
{{#Hint}}
<div id="hint">Hint:</div>
<div id="hidden">{{Hint}}</div>
{{/Hint}}
```

Add this in styling template:

```
#hidden {
  display: none;
}
#hint:hover + #hidden {
  display: block;
}
```
