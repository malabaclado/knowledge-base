## Chapter 1: Introduction to Data Science
- **Data science** is an *inter-disciplinary field* that uses many tools and skills in order to harness the knowledge from all the large pools of *structured and unstructured data* that has been gathered.
- Data science does not only require analysis skills, it also includes skills in
	- gathering data
	- analyze data
	- clean and convert data
	- programming skills to use algorithms and machine learning 
	- domain knowledge
	- ability to properly visualize and communicate insights
- In this program, you will learn the methods, algorithms, processes and tools needed in data science. 
- You will learn skills in: Python, SQL, ML algorithms, data visualization.

## Chapter 3. Introduction to Artificial Intelligence, Machine Learning, Deep Learning and Data Science

- What is Artificial Intelligence? 
	- AI is the idea that machines and comuter programs have the capacity to think, reason out, understand and learn like humans.
- What is the main objective of AI?
	- The main objective of AI processes is to teach machines from experience, feeding the right information and self-correction as an integral part of its development.
- What is machine learning?
	- is used in situations where we want machines to learn from large amounts of available data then apply the knowledge it gains on new data that is fed into the system.
	- It is like teaching a dog what a dog is by showing different pictures of dogs, so that when it sees a four-legged furry animal, it identifies it as a dog.
- **Machine learning is a subset of artificial intelligence.**
- **Deep learning is an advancement or a subset of machine learning.**
- What is deep learning?
	- happens when the amount of data that needs to be processed exceeds the tools and techniques needed for machine learning.

## Chapter 4. Machine Learning Part 1
- Machine learning 
	- is a discipline that focuses on studying computer algorithms that improve a computer system's decision making, pattern identification or predictive accuracy over time.
	- it allows cumputer systems to be trained on data.
	- is used to teach computers to accomplish tasks where no immediate program solution is available.
- In 1959, the term machine learning was coined by Arthur Samuel.
- Machine learning started mostly with pattern recognition.
- In 1990s, machine learning deviated from artificial intelligence as its own field. It focused more on algorithms from statistics and probability theory.
- How does a machine learn?
	- ML uses learning algorithms which are programs that adjust themselves (their parameters) based on feedback from their own predictions.
