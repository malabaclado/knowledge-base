# Second-brain Setup
- Digital inbox 👉 a place to store/dump information 
- Anki 👉spaced-repetition, to enhance recall and commit to long-term memory 
- Obsidian 👉 second-brain/linked thoughts/feynman technique 
- Notion 👉databases, goal tracking, web dump
- Ticktick 👉 Task management, Focus app, Habit tracker

---
The 4 steps to improved long-term memory:

1. Turn off phone notifications (during early and work hours)
2. Recall what you learn
3. Use The Feynman Technique
4. Learn in reps, not in a single sprint
