
Statistical Inference - is the process of approximating a parameter from an unknown distribution based on a given sample. 

Random Sample - a set of independent and identically distributed random variables

Statistic - a function of the random sample $T=T(X_1,X_2,...,X_n)$

Realization - a realized value of the statistic $t=T(x_1,x_2,...,x_n)$

Sampling Distribution - the probability distribution of a statistic  obtained through a large number of sample from a specific populations

Estimator - is a statistic that approximates a parameter. An estimator is an ==unbiased estimator== if $\mathbb{E}[T]=\theta$. Otherwise, if $\mathbb{E}[T]\neq \theta$ then it is a ==biased estimator==.

For a statistic T that is a linear combination of the random sample $T=\sum^n_{i=1}a_i Xi$ provided that we have: $$\mathbb{E}[T]=\sum^n_{i=1}a_i \mathbb{E}[X_i]$$
