# Terminal Bash Commands
- `pwd` -- prints the current working directory; stands for *present working directory*
- `ls` -- lists all files in the current working directory; stands for *list*
- `touch <filename>` -- create file
- `mkdir <folder name>` - create folder/directory
- `cp <file> <directory>` - stands for *copy*, copies files
- `cp -r <file/folder> <directory>` -- recursively copies files and directories 
- `mv <file> <directory>` -- used to move a file to another directory; can also be used to rename files
- `mv <file name> <new name>`  -- used to rename a file; 
- `find <folder>` -- prints a working tree branch of the directory; when folder is not mentioned, will print the working tree branch of the current working directory
- `find -name <file/folder name>` -- searches the location of a specific file ot folder name
