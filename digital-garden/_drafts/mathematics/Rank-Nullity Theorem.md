# Rank-Nullity Theorem

> [!NOTE] Theorem 
> Let $T: V \to W$ be a linear transformation with $\text{dim } V = n$. Then $$\text{dim}(\text{ker } T )+ \text{dim}(\text{im }T) = \text{dim }V$$
