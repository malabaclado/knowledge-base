### Setup
To obtain a Lagrange polynomial of order at most three, we chose 4 nodes to interpolate: (0.2, 0.6), (0.3,1.9), (0.5,9.9), (0.7,29.1). For the Newton's interpolating polynomial, we picked 5 nodes (0.2, 0.6), (0.3,1.9), (0.5,9.9), (0.7,29.1) and (0.8,44.4). For the cubic spline interpolation, we'll use the natural cubic cpline variation, meaning we'll set the derivatives of the first and last spline to zero.


### Results:
Approximation of f(0.4) using Lagrange Interpolation:4.8000
Approximation of f(0.4) using Newton Interpolation:4.8000
Approximation of f(0.4) using Cubic Spline Interpolation:4.8412



The Lagrange interpolating polynomial and Newton's interpolating polynomial gives exactly the same approximation of f(0.4) and exactly the same graph over the interval [0,1]. These polynomials are of order 2. The reason for this is because the the values are all increasing (the derivative is always positive) but not in a way that they are collinear.

![[figure1.png]]

The cubic spline interpolating polynomial on the other hand, is of order 3. It looks exactly like the graph of the Lagrange and Newton's interpolating polynomial with a slight deviation in values between nodes. This is because the cubic spline takes into consideration the curvature (the second derivative) of the polynomial. For x>0.8, the cubic spline polynomial seems to separate from the graph of the other two. This is because we set the derivatives for the first and last spline to zero.
