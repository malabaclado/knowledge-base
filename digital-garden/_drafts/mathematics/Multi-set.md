# Multi-set
*Definition.* A multi-set is a collection of objects where members need not be distinct.

![[Pasted image 20220316140702.png]]

![[Pasted image 20220316140819.png]]

*Remark*
1. The number $r_{i}$ is called the *repetition number* of $a_{i}$
2. The symbol $\infty \cdot a_{i}$ means that $a_{i}$ is repeated an infinite number of times.
