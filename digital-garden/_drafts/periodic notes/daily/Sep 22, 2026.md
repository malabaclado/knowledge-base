In FastAPI, a literal response_model_exclude=True is not standard and will typically result in a type or validation error,
  because response_model_exclude expects a set or dictionary of specific fields to omit (e.g.,
  response_model_exclude={"password", "secret_key"}).

  However, you might be referring to one of FastAPI's actual boolean exclude parameters:

   1. response_model_exclude_none=True
      * What it does: It filters out any fields from the final JSON response that have a value of None.
      * Example: If a schema has an optional field notes: Optional[str] = None, and the returned object has notes = None, that
        key will be completely omitted from the JSON output.

   2. response_model_exclude_unset=True
      * What it does: It excludes fields that were not explicitly set when creating the Pydantic model (i.e., those that fell
        back to their default values).

   3. response_model_exclude_defaults=True
      * What it does: It excludes fields whose values are exactly equal to their defined default values.
