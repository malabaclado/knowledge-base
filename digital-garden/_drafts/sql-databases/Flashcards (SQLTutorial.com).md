The {CASE} SQL expression allows you to evaluate a list of conditions and returns one of the possible.
^1676879742006

The CASE expression has two formats: {simple CASE} and {searched CAS}E.
^1676879742011

You can use the CASE expression in a clause or statement that allows a valid expression. For example, you can use the CASE expression in statements such as {SELECT}, {DELETE}, and {UPDATE} or in clauses such as {SELECT}, {ORDER BY}, and {HAVING}.
^1676879742014

On CASE statements, if you omit the ELSE clause and the expression does not match any expression in the WHEN clause, the CASE expression returns {NULL}.
^1676879742017
