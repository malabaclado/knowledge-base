# Summary
### Determining the Hyperplane

*(Proposition 1)*  The vector $\text{w}$ is perpendiccular to the hyperplane


*(Proposition 2)* $||\text{w}||$ need to be small to maximize the margin width

So to find the maximum margin hyperplane, we solve the optimization problem: $$\min \frac{1}{2}||\text{w}||$$
subject to the constraint: $$y_{i}(\text{w}^{T}\text{x}_{i}+ b) \geq 1$$
wherein (the data encoding) $y_{i}= +1$ for class B and $y_{i} = -1$ for class A.
