# Summary

**Support Vector Regression**
- Uses the support vector machine to solve regression problems.
- The margin lines are chose so that they cover all the data (hard margin) or allow for some violation (soft margin).

**SVR vs LR (Linear Regression)**
- SVR (with hard margin) are **more sensitive** to outliers
- SVR (with soft margin) is more insesntitive to inner data points.
- LR considers all data points into account while SVR consider only the support vectors
- SVR can tackle non-linear data distributions with the help of kernel tricks
