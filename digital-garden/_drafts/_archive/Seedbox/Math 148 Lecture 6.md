# Lecture 6
###### Definition: Order of a [[Projective Plane]]
A projective plane is said to be of order *n* if a line in the projective plane has exactly *(n+1)* points.

Fano Plane is an *order 2* projective plane.
The 13-point projective geometry is an *order 3* projective plane.

###### Order and Number of Points
If the order of the projective plane is *n*, then the total number of points is $n^{2}+ n + 1$. 

Let q = n+1. Number of points: $q^{2}-q + 1= n^{2}+n +1$

If *p* is prime, there is a projective plane of order $p^{k}$ for any positive integer *k*. 

Recall:  If $\mathbb{F}$ is a finite field, the order $|\mathbb{F}|=p^{k}$

Trivia: Finite projective planes are considered as 3-dimensional finite spaces over vector fields.

###### Constructing the Real Projective Plane
- Consider the Euclidean plane $\mathbb{R}^2$
- For a given pair of parallel liens *l* and *l'*, we introduce a point where *l* and *l'* meet. 
	- This point is called the **ideal point** *(point at infinity)*
	- ![[Pasted image 20220311040216.png|100]]
- There is going to be one ideal point for every family of parallel lines, so there are infinitely many ideal points in  $\pi(\mathbb{R})$.
- Each line in $\pi(\mathbb{R})$ has exactly one ideal point.
- The set of all ideal points forms a line called the **ideal line**. 

==The real projective plane is just the Euclidean plane together with the ideal line.==
