# Hyperparameter Tuning

## Three Phases of Parameter Tuning 

Phase 1: Starting baseline parameters 
Phase 2: Manual tuning or grid search & more feature engineering 
Phase 3: Random search or Bayesian optimization and final feature engineering 


## Four Basic Methodologies of Hyperparameter Tuning 
1. Manual Tuning 
2. Grid Search 
3. Randomized Search 
4. Bayesian optimization 






Note that hyperparameters cannot be learned by fitting the model.

### Choosing the correct hyperparameter
1. Via [[GridSearchCV in scikit-learn]]
