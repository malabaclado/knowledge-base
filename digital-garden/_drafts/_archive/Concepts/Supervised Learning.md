# Supervised Learning


[[Supervised Learning]] is a type of [[Machine Learning]] where the training data is labeled. ^[Datacamp: [[Datacamp - Supervised Learning with Scikit learn]]]


The goal of [[Supervised Learning|supervised learning]] is to predict the target variable from a set of labeled data.

If the target variable is a category, we call it a [[classification]] task. If the target variable is a continuous variable, then we call it a [[regression]] task.

USES OF [[Supervised Learning | SUPERVISED LEARNING]]
- Automating time-consuming or expensive manual tasks
- Make predictions bout the future
