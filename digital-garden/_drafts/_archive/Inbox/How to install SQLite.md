# How to install SQLite
1. Download the package (zip) from [SQLite Download Page](https://www.sqlite.org/download.html)
2. Extract the contents to your desired folder.
3. Navigate to your desired folder, copy the directory, go to Environment Variables and add the directory to PATH.
4. Open the command prompt enter `sqlite3`


# How to create a database
1. Go to the folder where you want your database to be located.
2. Open command prompt and enter `sqlite3 [name_of_your_database].db`. This creates a database on that folder.
3. To see the database, enter `.databases`
